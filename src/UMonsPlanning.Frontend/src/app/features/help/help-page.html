Aide : ajouter votre lien de calendrier

Une fois votre lien généré depuis la page d'accueil, vous n'avez besoin de l'ajouter qu'une seule fois dans votre application de calendrier, via son option « S'abonner à un calendrier par URL » (le nom exact varie d'une application à l'autre). Voici la marche à suivre pour les applications les plus courantes :

    {{ link.instructions }}
